# Arquitetura do GereIgreja

Esta pasta reúne toda a documentação arquitetural da plataforma.

Finalidade da pasta:

- registrar decisões de arquitetura da solução;
- consolidar visão sistêmica da plataforma;
- manter referência de componentes e relações técnicas.

Aqui estão definidos:

- Arquitetura Backend
- Arquitetura Frontend
- Arquitetura Modular
- Banco de Dados
- APIs
- Infraestrutura
- Fluxos internos

Toda decisão arquitetural deverá ser registrada nesta pasta.

## Como criar um novo documento de Arquitetura

1. Confirme que o tema é arquitetural e transversal (não específico de um único app).
2. Escolha o próximo número disponível na sequência.
3. Nomeie no padrão `NN-Tema.md`.
4. Registre contexto, decisão, impactos e riscos.
5. Atualize este README e o `docs/INDEX.md`.

## Padrão de Nomenclatura

- `NN-Tema.md`
- Dois dígitos para preservar ordenação.
