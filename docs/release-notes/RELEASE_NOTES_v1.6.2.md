# RELEASE_NOTES_v1.6.2.md

## Gereigreja v1.6.2 (25/03/2026)

### Tipo de atualização
- **Correção de bugs** (patch release)

### Melhorias e correções
- Correções gerais de estabilidade e pequenos bugs identificados após o último deploy.
- Ajustes finos em funcionalidades já existentes para garantir melhor experiência e confiabilidade.
- Nenhuma nova funcionalidade foi adicionada nesta versão.

### Recomendações
- Recomenda-se atualizar para esta versão para garantir o funcionamento estável do sistema.
- Consulte o arquivo `melhorias no gereigreja.txt` para histórico detalhado de melhorias e sugestões em andamento.

---

✅ Correção no cadastro de pessoas: Agora os botões “Salvar” e “Salvar e Continuar” funcionam conforme esperado, tornando o fluxo mais intuitivo.
✅ Seleção e salvamento de tags: Ajustamos a lógica para garantir que as tags sejam selecionadas e salvas corretamente no cadastro de membros.
✅ Aprimoramento dos arquivos estáticos: Organizamos e corrigimos a entrega dos arquivos JS/CSS, evitando problemas de cache e carregamento.
✅ Melhorias de usabilidade: Mensagens de feedback mais claras e navegação mais fluida em todo o sistema.
✅ Outros pequenos ajustes e correções de bugs identificados pelos usuários.
Agradecemos a todos que reportaram problemas e sugeriram melhorias!
Continue enviando seu feedback para juntos fazermos um Gereigreja cada vez melhor.
