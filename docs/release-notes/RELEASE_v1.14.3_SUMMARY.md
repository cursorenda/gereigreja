# RELEASE v1.14.3 - Padronização de Documentação de Engenharia

Data: 10/07/2026

## Resumo Executivo
A release v1.14.3 consolida a padronização documental do GereIgreja com novos frameworks e guias técnicos de backend, arquitetura e produto. O objetivo é profissionalizar a base de conhecimento, reduzir ambiguidade técnica e acelerar onboarding, manutenção e governança de código.

## Entregas Principais
- Novo bloco de documentação backend (GBE-01 a GBE-09) com padrões de estrutura, core, apps, models, services, selectors, managers, views e forms.
- Consolidação dos frameworks de engenharia em `docs/frameworks/` com identidade e padrão único.
- Expansão da arquitetura em `docs/arquitetura/` com novos documentos de APIs, segurança, multi-tenant e core.
- Documentação de produto do Hinário formalizada em `docs/produto/` para base jurídica, especificação funcional, portal do usuário e fase concluída.

## Impacto
- Melhora a consistência de decisões técnicas entre equipes e módulos.
- Reduz tempo de onboarding de novos desenvolvedores.
- Estabelece linguagem comum para arquitetura, revisão de PR e evolução de plataforma.
- Eleva o nível de governança técnica e previsibilidade do sistema.

## Escopo
- Mudança documental (sem alteração de schema ou lógica de runtime nesta release).
- Sem migrações de banco.

## Validação
- Revisão estrutural das pastas de documentação.
- Changelog atualizado com a versão correspondente.
- Versionamento e push concluídos para disparo do deploy padrão do projeto.
