# RELEASE v1.14.8 - Documentação Frontend

A release v1.14.8 consolida a revisão completa da documentação frontend do GereIgreja, introduzindo novos arquivos de referência e corrigindo ambiguidades sobre a arquitetura do sistema. A documentação passa a refletir com precisão a distinção entre a Administração Técnica (Django Admin) e a Área de Gestão do GereIgreja, além de reconhecer explicitamente o estado de migração em curso no codebase.

## Entregas principais
- Revisão dos documentos existentes:
  - `01-Frontend-Architecture.md` — arquitetura geral atualizada.
  - `02-Estrutura de Pastas.md` — renomeado e revisado.
  - `03-Componentes.md` — padrões de componentes revisados.
  - `04-Layouts.md` — hierarquia de layouts documentada.
  - `docs/governanca/07-Padroes-de-Templates.md` — padrões de templates atualizados.
  - `docs/templates/ARQUITETURA_TEMPLATES.md` — arquitetura de templates revisada.
- Novos documentos criados:
  - `05-Templates.md` — guia de templates Django.
  - `06-Assets.md` — gestão de arquivos estáticos.
  - `07-CSS.md` — convenções de CSS e Bootstrap.
  - `08-JavaScript.md` — padrões de JavaScript no projeto.
  - `09-HTMX.md` — uso de HTMX no GereIgreja.
  - `README.md` — índice da documentação frontend.

## Benefícios
- Clareza sobre a diferença entre Django Admin e Área de Gestão.
- Referência oficial para novos desenvolvimentos frontend.
- Documentação realista que reconhece a migração em andamento.

## Validação
- Revisão manual de todos os documentos.
- Sem impacto em código de produção (apenas documentação).
