# Release Notes — Índice e preservação histórica

Esta pasta reúne as release notes documentadas do GereIgreja. Cada arquivo `RELEASE_vX.Y.Z_SUMMARY.md` é um registro histórico por versão; sua existência, isoladamente, não comprova publicação ou implantação em produção.

## Preservação histórica

- Paths, comandos, nomes de diretórios e referências dentro de uma release podem refletir a estrutura válida quando ela foi documentada.
- Não reescreva retrospectivamente uma release antiga apenas para alinhá-la à estrutura atual.
- Correções em registros históricos devem se limitar a erro factual comprovado, link quebrado ou esclarecimento que não altere o registro.
- Para a estrutura vigente do projeto, consulte o [Índice Mestre da Documentação](../INDEX.md) e o README ou documento canônico da família correspondente.
