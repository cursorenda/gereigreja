# 05 - Mapa Mestre de Palavras-Chave

## Objetivo

Mapear todas as intenções de busca relacionadas à gestão ministerial, conectando cada pesquisa realizada pelos usuários à melhor resposta dentro do ecossistema do GereIgreja.

Este documento servirá como referência para a criação de novas páginas, artigos, guias, materiais educativos e campanhas de marketing.

---

# Nossa Filosofia

Não produziremos conteúdo baseado apenas em palavras-chave.

Produziremos conteúdo para responder problemas reais enfrentados por igrejas.

Cada pesquisa realizada por um pastor, secretário, tesoureiro ou líder representa uma oportunidade de ajudar alguém.

Quando ajudamos primeiro, conquistamos confiança.

Quando conquistamos confiança, a conversão acontece naturalmente.

---

# Como organizaremos as pesquisas

Todas as palavras-chave serão classificadas em seis dimensões.

## 1. Intenção de Busca

Cada pesquisa deverá ser classificada conforme seu objetivo.

### Informacional

O usuário deseja aprender.

Exemplos:

- Como organizar uma igreja
- Como cadastrar membros
- Como fazer prestação de contas

---

### Navegação

O usuário procura uma marca específica.

Exemplos:

- GereIgreja
- Sistema GereIgreja
- Login GereIgreja

---

### Comercial

O usuário compara soluções.

Exemplos:

- Melhor sistema para igreja
- Software para igreja
- Sistema para congregação

---

### Transacional

O usuário deseja começar imediatamente.

Exemplos:

- Testar sistema para igreja
- Sistema para igreja grátis
- Cadastro igreja online

---

# 2. Persona

Cada palavra deverá atender um público específico.

Exemplos:

- Pastor
- Secretário
- Tesoureiro
- Administrador
- Professor EBD
- Líder Ministerial

---

# 3. Módulo do GereIgreja

Cada pesquisa deverá apontar para um módulo do sistema.

Exemplos:

- Secretaria
- Financeiro
- Agenda
- Eventos
- Escola Bíblica
- Relatórios
- Usuários
- Permissões

---

# 4. Tipo de Conteúdo

Cada intenção deverá possuir o formato mais adequado.

Exemplos:

- Página Pilar
- Guia Completo
- Artigo
- FAQ
- Checklist
- Tutorial
- Glossário
- Caso de Uso

---

# 5. Objetivo da Página

Toda página criada deverá possuir um único objetivo principal.

Exemplos:

- Atrair visitantes
- Educar
- Gerar autoridade
- Converter
- Apoiar outra página

---

# 6. Próximo Passo

Nenhum conteúdo deverá terminar sem direcionamento.

Exemplos:

- Ler outro artigo
- Conhecer um Guia
- Explorar a Demonstração
- Criar uma conta gratuita
- Conhecer os Planos

---

# Estrutura do Mapa

Cada palavra-chave cadastrada deverá conter:

- Palavra principal
- Palavras relacionadas
- Intenção
- Persona
- Categoria
- Página destino
- CTA
- Módulo relacionado
- Prioridade
- Status

---

# Atualização Contínua

O Mapa Mestre deverá ser atualizado sempre que:

- Novos módulos forem criados.
- Novas funcionalidades forem lançadas.
- Surgirem novas oportunidades de pesquisa.
- O comportamento dos usuários mudar.

---

# Princípio Fundamental

O objetivo do GereIgreja não é disputar posições no Google.

Nosso objetivo é responder às dúvidas mais importantes sobre gestão ministerial com o conteúdo mais útil, confiável e completo disponível em língua portuguesa.
