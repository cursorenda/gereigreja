# 09 - SEO On-Page

# Objetivo

Definir os padrões oficiais de otimização On-Page utilizados pelo GereIgreja.

Este documento estabelece regras para criação de páginas, artigos, guias, tutoriais e páginas pilares, garantindo consistência, qualidade e melhor desempenho orgânico nos mecanismos de busca.

---

# Filosofia

O SEO do GereIgreja deve existir para melhorar a experiência do usuário.

Não produziremos conteúdo para algoritmos.

Produziremos conteúdo para pessoas.

Toda otimização deverá tornar o conteúdo mais útil, mais claro e mais fácil de encontrar.

---

# Palavra-Chave Principal

Todo conteúdo deverá possuir uma palavra-chave principal.

A palavra-chave principal deverá:

- Representar a intenção de busca principal.
- Estar alinhada com a persona.
- Possuir relação direta com o conteúdo.

Exemplos:

- Sistema para Igreja
- Gestão Financeira para Igrejas
- Cadastro de Membros
- Escola Bíblica Dominical

---

# Título SEO

Todo conteúdo deverá possuir um título otimizado.

Boas práticas:

- Conter a palavra-chave principal.
- Ser claro.
- Gerar interesse.
- Possuir entre 50 e 60 caracteres quando possível.

Exemplo:

Como Organizar a Secretaria da Igreja em 2026

---

# URL Amigável

As URLs devem ser simples.

Exemplos:

/blog/gestao-financeira-igrejas/

/blog/cadastro-de-membros/

/blog/como-organizar-secretaria-igreja/

Evitar:

- URLs longas
- IDs desnecessários
- Caracteres especiais

---

# Meta Description

Toda página deverá possuir meta description exclusiva.

Objetivos:

- Aumentar CTR.
- Explicar o conteúdo.
- Estimular o clique.

Boas práticas:

- Entre 120 e 160 caracteres.
- Linguagem clara.
- Chamada para ação quando apropriado.

---

# Estrutura de Títulos

Todo conteúdo deverá seguir hierarquia semântica.

Modelo:

H1 → Título principal

H2 → Seções principais

H3 → Subseções

H4 → Detalhamentos específicos

Nunca utilizar títulos apenas por aparência visual.

---

# Introdução

A introdução deverá:

- Explicar o problema.
- Demonstrar relevância.
- Confirmar a intenção de busca.
- Preparar o leitor para o conteúdo.

A palavra-chave principal deverá aparecer naturalmente nos primeiros parágrafos.

---

# Conteúdo Principal

Todo conteúdo deverá:

- Responder a intenção de busca.
- Utilizar linguagem clara.
- Apresentar exemplos práticos.
- Utilizar listas quando necessário.
- Possuir profundidade adequada.

O objetivo é resolver a dúvida completamente.

---

# Palavras Relacionadas

Além da palavra principal, o conteúdo deverá utilizar termos semanticamente relacionados.

Exemplo:

Palavra principal:

Sistema para Igreja

Relacionadas:

- Gestão de Igrejas
- Software para Igreja
- Administração Eclesiástica
- Cadastro de Membros
- Gestão Financeira

---

# Imagens

Toda imagem deverá:

- Possuir nome descritivo.
- Possuir atributo ALT.
- Ser otimizada para web.
- Ter relação direta com o conteúdo.

Exemplo:

cadastro-membros-gereigreja.webp

ALT:

Tela de cadastro de membros no GereIgreja

---

# Links Internos

Todo conteúdo deverá conter links internos.

Mínimo recomendado:

- 2 links para conteúdos relacionados.
- 1 link para Página Pilar.
- 1 CTA para demonstração ou cadastro.

---

# FAQ

Sempre que possível incluir perguntas frequentes.

Benefícios:

- Melhor experiência do usuário.
- Oportunidade para rich snippets.
- Ampliação de palavras-chave relacionadas.

---

# Experiência do Usuário

O conteúdo deve ser fácil de consumir.

Boas práticas:

- Parágrafos curtos.
- Listas.
- Destaques.
- Espaçamento adequado.

Evitar blocos extensos de texto.

---

# Atualização de Conteúdo

Todo conteúdo deverá ser revisado periodicamente.

Motivos:

- Mudanças de legislação.
- Novas funcionalidades.
- Mudanças de mercado.
- Novas oportunidades de SEO.

---

# CTA

Toda página deverá possuir chamada para ação.

Exemplos:

- Conhecer o GereIgreja
- Criar Conta Gratuita
- Solicitar Demonstração
- Conhecer Funcionalidades

A CTA deverá surgir naturalmente.

---

# Checklist SEO On-Page

Antes de publicar verificar:

- Palavra-chave principal definida
- URL amigável
- Título otimizado
- Meta description criada
- Estrutura H1-H4 correta
- Imagens otimizadas
- ALT preenchido
- Links internos adicionados
- CTA inserido
- FAQ criado quando aplicável

---

# Princípio Fundamental

O melhor SEO On-Page é aquele que melhora a experiência do visitante.

Quando o conteúdo é útil, claro e resolve o problema do usuário, o SEO se torna consequência natural da qualidade entregue.
