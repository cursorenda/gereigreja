# UI — GereIgreja Design System (GDS)

Esta coleção reúne toda a documentação referente à interface do GereIgreja.

Inclui:

- Identidade visual
- Componentes
- Templates
- Tokens CSS
- Tipografia
- Layouts
- UX
- Acessibilidade
- Boas práticas de Front-end

Toda interface desenvolvida para o GereIgreja deverá seguir as diretrizes estabelecidas nesta coleção.
