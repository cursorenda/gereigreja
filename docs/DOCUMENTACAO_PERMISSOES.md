# Documentação de Permissões Customizadas

Este documento detalha as permissões customizadas do Gereigreja, sua aplicação e boas práticas.

## 1. Introdução
- O sistema utiliza permissões customizadas para controlar o acesso granular a funcionalidades específicas.
- Todas as permissões devem ser documentadas e centralizadas.

## 2. Padrão de Nomenclatura
- Consulte [DOCUMENTACAO_PADRAO_GRUPOS.md](DOCUMENTACAO_PADRAO_GRUPOS.md) para o padrão oficial de nomenclatura de grupos e permissões.

## 3. Permissões Customizadas
- Descreva aqui cada permissão customizada, seu propósito e onde é utilizada.

## 4. Boas Práticas
- Sempre utilize constantes para nomes de permissões.
- Documente toda permissão criada ou alterada.
