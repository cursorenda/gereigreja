# Qualidade

Documentação dos processos de qualidade.

Finalidade da pasta:

- definir critérios de qualidade e gates de release;
- consolidar checklists de validação;
- registrar práticas de testes e revisão contínua.

Inclui:

- Testes
- Cobertura
- Auditorias
- CI/CD
- Boas práticas
- Revisões

## Como criar um novo documento de Qualidade

1. Defina o tipo (checklist, política, padrão, auditoria).
2. Nomeie no padrão `MODULO_TEMA_TIPO.md` quando for específico de módulo.
3. Use `TEMA_TIPO.md` para documento transversal.
4. Liste critérios objetivos de aprovação/reprovação.
5. Atualize este README e o `docs/INDEX.md`.

## Padrão de Nomenclatura

- Módulo específico: `COMUNICACAO_TEMA_TIPO.md`
- Transversal: `TEMA_TIPO.md`
