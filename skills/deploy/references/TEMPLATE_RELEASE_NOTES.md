# 📝 Template para Notas de Versão do Gereigreja

## Como Solicitar
Quando precisar gerar notas de versão, basta dizer:

**"Crie as notas de versão no estilo amigável para os usuários"**

ou

**"Faça o texto de atualização de versão para usuários"**

ou simplesmente:

**"Notas de versão para usuários"**

---

## Formato Padrão (Exemplo v1.0.9)

### Estrutura:
1. **Título com emoji e data** 🎉
2. **Funcionalidade principal** com descrição detalhada
3. **Melhorias secundárias** organizadas por seção
4. **Dica de uso prático** 💡
5. **Rodapé com suporte e versão**

### Elementos que tornam o texto atraente:
- ✅ Emojis para destaque visual
- 📋 Listas organizadas e escaneáveis
- 💡 Dicas práticas de uso
- 🎯 Linguagem simples e direta
- ℹ️ Instruções de "Como acessar"
- 📈 Benefícios claros para o usuário

### Tom de Comunicação:
- Amigável e acessível
- Focado nos benefícios para o usuário
- Evita termos técnicos
- Destaca o que mudou e por que é útil
