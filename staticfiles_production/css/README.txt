Organização sugerida para CSS do Gereigreja:

- layout.css: ajustes de espaçamento, containers, cards, grids
- botoes.css: estilos de botões
- formularios.css: inputs, labels, validação
- cores.css: paleta de cores e utilitários
- fontes.css: tamanhos de fonte e acessibilidade
- acessibilidade.css: alto contraste, etc.

Inclua todos no template base, após o Bootstrap/styles.css.

Exemplo de uso para tamanho de fonte:
<body class="font-size-grande"> ... </body>
